A row is one sidebar item as configured. The same page can appear in more than one sidebar (for example a page reachable from both the Admin and HR sidebars), and some items carry a different label per role — the `labelByRole` column of the CSV holds those variants. The label shown in this report is the default label.

## How to read the table

- **Group** is the admin domain (Overview, People, Payroll, Orders & CRM, Hiring, Platform …) for the Admin sidebar, and the section heading for the HR and Employee Portal sidebars.
- **External integrations in use** lists the existing integrations (EX-xx, report 02) that the module depends on.
- **New opportunities** lists the recommendations (INT-xxx, report 07) that would change the module.
- Work with no sidebar row is never forced onto one. It is labelled `BACKGROUND SERVICE — NO SIDEBAR ENTRY` (scheduled jobs, webhooks, backups) or `INTERNAL COMPONENT — NO SIDEBAR ENTRY` (libraries, headers, database internals) in reports 02, 07 and 13.
- A capability that would need a screen that does not exist is labelled `PROPOSED NEW MODULE — NOT PRESENT IN CURRENT SIDEBAR` and is kept out of this list (see report 10).
