### Production hooks (moved from AGENTS.md §2.3)

- **A PARTIAL `CRON_SECRET` rotation leaves TWO fingerprints, and Healthchecks `up` is not proof.** The past 401s are resolved: **rotate NOTHING.** 🔴 **`len` is 64, NOT the 71 this line claimed until 2026-09-30** — measured, and it authorizes (8 cron calls, all 200, zero 401). - **`CRON_SECRET` flows GitHub → Railway** (`sync-railway-production-secrets.yml` overwrites Railway) — **rotate GitHub first.** The 4 OFF iReports360 jobs are DELIBERATE.
- **The cron-job.org REST API allows 100 requests per DAY** — a bulk edit costs ~34 and CANNOT be rolled back.
- 🔴 **Auth metadata keys `phoenix_role`, NOT `role`** — a migration writing `role` matches 0 rows and VERIFIES ITSELF GREEN on the wrong key. And `banned_until` is NOT deactivation: authority is `is_active` + `employment_status`. `auth-metadata-role-key-is-phoenix-role-not-role` · `deactivated-accounts-are-mostly-not-banned-at-the-auth-layer`
- 🔴 **A ROUTE THAT RECEIVES A BODY OVER 10 MB (AN APK, A VIDEO) MUST BE EXCLUDED FROM `proxy.ts`'s `config.matcher` BY EXACT PATH — NEVER FIX IT BY RAISING `proxyClientMaxBodySize`.** A matched request's body is copied for the proxy and cut at 10 MB with only a console warning, so the route's `formData()` throws and the user reads a misleading "choose a file" error (staging, 2026-10-04: `Request body exceeded 10MB for /api/devices/headwind/upload`; both device upload routes were dead until then). Raising the limit makes the proxy buffer that much of ANY unauthenticated body on any path. An excluded route loses the proxy's CSRF layer, so it must itself call `assertSameOriginMutation` and its permission check BEFORE reading the body. Audited 2026-10-04: ONLY routes whose own limit is above 10 MB are excluded — the two device APK uploads, hiring documents, custom hiring-pack templates, mailbox send, the WhatsApp inbox, an employee's CV and its staging draft; vacations already streams big files straight to Storage, and a PUBLIC route (`/api/public/apply`) keeps the ceiling. Pinned by `tests/proxy-upload-body-limit.test.ts`, whose `EXCLUDED` table a new entry must join.

### Navigation

- 🔴 **`/hr/<x>` IS A `proxy.ts` REWRITE ONTO `/<x>`, SO THERE IS NO `app/**/hr/**` FOLDER AND ITS ABSENCE IS CORRECT.** `/hr/employees` serves `app/(admin)/employees/page.tsx`; a sweep that checks an `/hr` href against the route tree concludes the row 404s when it does not (reported that way 2026-10-06, with a repoint to `/employees` proposed). Repointing is a double regression — `app-shell.tsx` redirects an HR seat off a bare admin address back into the namespace via `toHrNamespacePath`, and `tests/hr-url-namespace.test.ts` requires every HR row to be authored under the prefix. Strip the prefix with `hrNamespaceRemainder` before resolving, gated on `isHrRewritablePath` and NEVER the broader `isHrNamespacePath` — `/hr/api/**` is deliberately not rewritten (the CSRF guard is scoped to `/api/`), so stripping there resolves an address nothing serves. Take the query off BEFORE the test: `/hr?tab=x` is in the namespace yet matches neither spelling. Pinned by `tests/nav-hrefs-resolve.test.ts`, which checks all four nav catalogues.

### Auth audit

- 🔒 **EVERY REJECTED SESSION REQUEST KEEPS ITS OWN `audit_logs` ROW — do not de-duplicate them** (owner, 2026-10-04, asked directly after the performance review measured 1,728 rejection rows in 14 days, 92% repeats of one session and reason). `auditSessionRejection` in `src/lib/auth/server.ts` stays one row per rejection; the Operations page's 24-hour auth count reads them. Never re-propose a per-session window.

### Design tokens

- 🔴 **`rounded-full` IS THE ONE RADIUS CLASS NO `--phx-radius-*` TOKEN REACHES, SO IT IS SQUARE ONLY INSIDE `.admin-shell` AND `.employee-portal-shell`.** Compiled from the real `globals.css` and measured 2026-10-06: `.rounded-full` emits `border-radius: calc(infinity * 1px)`, a Tailwind literal, while every other step emits a `var(--phx-radius-*)` that `tokens.css` sets to 0. The same badge markup reads **0px inside a shell** — RULE 1 zeroes `[class*="rounded"]` there — and **33,554,432px outside one**, the exact hazard `globals.css` already records for `--radius-3xl/4xl`. 🔴 **So "it looks square on this page" is NOT compliance with the square-edge golden rule**: a `rounded-full` is one mount outside the shell away from rendering a pill, with nothing to catch it. Use `rounded-md`, which is square by token in either context. 🔴 **And a route folder grep for the shell class CANNOT tell you whether a page is shelled** — `app/dev/employee-portals` carries none and still measured 0px, because it nests its badge inside `EmployeePortalChrome`, which applies `employee-portal-shell`: walk the import chain, never the folder.
