## Rules

- 🔴 **CV TEXT IS READ IN A WORKER THREAD WITH A 384 MB HEAP CEILING AND A 30 s DEADLINE (`cv-text-isolation.ts`), AND FREE OCR HAS A 60 s WHOLE-READ DEADLINE** (23 Oct 2026 audit, P5-04). A file past either limit is refused as `unsupported_file` and never retried in-process; only a thread that cannot LOAD its library falls back to the unchanged in-process reader (`extractRawTextInProcess`), logged once as `cv_parse_isolation_unavailable` — in a production image whose tracing dropped `word-extractor`, a legacy `.doc` takes that fallback. The thread runs the same calls with the same options, so the text is identical; keep the two readers in step. Pinned by `tests/cv-text-isolation.test.ts` and `tests/integration-deadlines.test.ts`.
