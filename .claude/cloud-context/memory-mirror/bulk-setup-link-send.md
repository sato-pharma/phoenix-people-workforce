Built a **bulk password setup/reset link** action on **Users & Access** (`/admin/access`) so a Super Admin can issue one-time login links to many users at once instead of clicking "Email link" per row. **#1501 MERGED** (squash `2e0cfeb9`) + **DEPLOYED to prod 2026-07-30** (dispatch deploy run 30537506014, ~10m; live route returns 403 not 404). Follow-up **#1504** (`75e27c0f`, MERGED+DEPLOYED 07-30) adds a **password-status filter** (All / Setup pending / Password ready) to the Users list so the admin can isolate never-logged-in users, then "Select all filtered" → Email links WITHOUT resetting active accounts — the safe onboarding path. Worktree `_wt-bulk-setup-link` was recycled onto branch `codex/setup-pending-filter` for #1504; CLEANABLE now (both PRs merged) after owner confirms. Directly serves the onboarding gap in [[adoption-is-the-gap-not-features]] (112 provisioned but most never set a password). Deploy note: fast-deploy window had expired (07:00Z), so merge→live needed a manual `gh workflow run deploy-cloud-run.yml`; the dispatch fired right after merge no-op'd (16s) because the deploy CI-gate needs main's post-merge CI green first — see [[prod-deploy-scheduled-not-on-push]].

- **Route:** `POST /api/admin/users/setup-link/bulk` — Super Admin only, loops the existing audited `sendPasswordSetupLink` per user, returns `{ sent, failed, capped, results[] }`. Email cap **100/batch** (respects Resend ~100/day, see [[resend-daily-100-cap-429-outage]]); copy cap 250; over-cap ids reported as "deferred", not dropped. New `parseBulkPasswordSetupRequest` validator.
- **UI:** row checkboxes + "Select all filtered" + toolbar (Email/Copy links) + results panel (copy mode exports `HR_ID<TAB>URL` to clipboard).
- 🔴 **Blast-radius caveat:** `sendPasswordSetupLink` bumps `session_version` + sets `force_password_reset=true` for EVERY processed user — **even copy mode**. So "select all" signs out and force-resets users who already have a working password. The bulk confirmation dialog spells this out and counts how many are already password-ready.
