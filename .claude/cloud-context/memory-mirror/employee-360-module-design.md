## 2026-09-04 — built; the caveats are what still matter

The description ended **"(design phase, no code yet)"**. On `main`:
`app/(admin)/employee-360/page.tsx` and `app/(admin)/employee-360/[hrId]/page.tsx`.

What has NOT changed is the data reality this file records, and it is the reason the file is
worth keeping now that the module exists: GPS check-ins are a partial feed and must never be
scored on, CRM campaign visits make a working rep look like a zero, and roughly a fifth of CRM
"doctors" are not doctors. A scoring module built without those caveats produces confident
numbers that are wrong about real people.
