**How to apply:**

- First READ the actual files, then reflect the data back simply: reframe the chaos as "a few kinds of things + duplicate copies" so they feel understood.
- Deliver AUTOMATION that removes the manual work (one repeatable script → one output file), not a checklist of manual steps.
- Lead with a clear recommendation; ask at most one or two low-effort (clickable) questions.
- Produce a real artifact — don't just plan.
- Calm, simple English (they may think in Arabic; per AGENTS.md reply in English).
