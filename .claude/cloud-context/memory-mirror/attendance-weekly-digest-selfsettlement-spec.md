**Core model shift:** stop all automatic deductions. Instead each in-scope **head-office employee** gets **exactly 4 weekly digests per 24→24 payroll cycle** (weeks Sun–Thu; weeks 1–3 normal, week 4 absorbs extra days to day 24; all 4 sent even if clean). Digest reconciles fingerprint punches against approved vacation, approved excuse, weekly/monthly-plan field days, and official holidays (on their **observed/postponed** date — admin gets alert, picks the real taken day on the calendar).

**Scope = ALL of:** Head Office line (line_id=4) AND active device mapping AND not a field title AND actively employed. Never DM/RM/Medical Reps. **Owner exempted the junior support staff** (OF-0001, A-1 Admin Assistants, A-4 Buffet). **Final in-scope = 8:** A-13 (Office Coordinator, ALSO the standing missing-punch verifier), A-16 (Talent Acq), B-185 (Finance Mgr), A-7 (Training Mgr), A-9 (Marketing Mgr), A-2 (SFE Mgr), B-10 (HR Mgr — an approver, so his own cases escalate to CEO), A-3 (QPPV, own Mon/Wed 09:30–14:30 policy). **TIER 2 — office-hybrid managers (NSM/GPM/PM), judged office-days-only:** 6 mapped/active = A-8 (Rasha GPM, already has own 10:00–16:00 policy = the "orphan" policy id 3), A-12 (Ali NSM), B-122 (Amr NSM), B-157 (Sameh NSM), B-155 (Ahmed PM), A-10 (Nahed PM). Plan/punch mismatch → **flag to manager, cc HR + CEO, NO auto-deduction** (office+no-punch = no-show flag; field+punch = anomaly flag). **DM/RM/Medical Reps fully OUT.**

**FLEXIBLE-HOURS ENGINE (new logic to build — engine today only does fixed schedule+grace):** standard 9:00–17:00, **min 7h50m presence**. Arrival free to **9:30 flex ceiling**; lateness counted **from 9:30** (10:00=30min late). Expected leave = arrival+7h50m (9:30 in → 5:20 out ok). **Completing hours HALVES a late penalty (exactly ÷2)** — 30min late = ½day but ¼day if hours completed. If BOTH late & short → **worse of the two** (not additive). **No banking.** Value = exact policy value, no rounding, each day stands alone. **Half-day leave splits at 1:00 PM** (AM half → in by 1PM; PM half → stay till ≥1PM). **Seasonal schedules** (Ramadan + any date range) auto-override. Owner sets exact times/brackets in admin UI; logic is fixed.

**Deductible events:** late (past 9:30), short-hours/early-leave, **missing punch** (only 1 punch → needs documented reason+proof; verification chain **A-13 confirms → HR → COO**; A-13 is standing verifier).

**Settlement (employee choice, per-day OR whole-week, editable until an approver acts):**
- **SALARY-ONLY (CEO/COO rejected the balance option 2026-07-03).** No balance/leave-deduction logic at all. Employee has **2 actions: Confirm or Dispute** (dispute = free-text reason + attachment).
- Digest shows per-day **quantity + EGP value**, weekly total, and running cycle total (EGP amounts ARE shown here — this is the settlement context, still keep amounts off the portal LANDING per [[portal-no-salary-on-landing]]).
- **No HR approval on a confirmed deduction** — a confirm (or auto-confirm) goes straight to governance→payroll. HR only reviews disputes.
- **48h silence from digest send → AUTO-CONFIRM → salary. No 24h nudge.**
- Dispute → HR Manager + System Admin, cc manager + CEO; if the subject is an approver, the others handle it; unresolved at day-24 cut-off → salary.
- Salary via existing audited deductions-governance → day-24 payroll import (÷30). Immutable record (action+time; for disputes reviewer+decision+reason+time; exact day-value + EGP; delivery/read proof).
- Salary outcomes flow through the **existing audited deductions-governance → day-24 payroll import**.
- Once decided the record is **permanent/immutable** (choice+time, approver+decision+time, exact value, delivery/read record).

**Language:** English. **Channels:** email + Telegram + in-portal. Replaces the old ad-hoc portal dispute screen. Old auto-deduction generator (payroll-candidates.ts) → **removed entirely**.

**Admin configures:** per-employee/title policy, approvers & CC list, message templates, holiday observed-date remap. Fixed by system: cycle/tiling, reconcile logic, immutability, ÷30, governance route.
